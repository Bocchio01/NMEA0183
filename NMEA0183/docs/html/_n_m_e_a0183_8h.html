Detailed Description

NMEA0183 Protocol Handling Library.

This library provides functionality for handling the NMEA0183 protocol, a standard for communication between marine electronic devices.

Parse data.

Parse data of the NMEA0183_t struct and store them in the registered_sensor_t struct corresponding to the correct sensor that has sent the sentence. This function calls the parse function defined in the sensor_t struct. If the sensor is not registered, the data are not parsed.
